# Face — Jiwon

흰 바탕에 검은 펜 선으로 그린 내 얼굴(버섯머리 + 동그란 안경).

## 실행 방법

```bash
cd intro-weather
python3 -m http.server 5174
```

브라우저에서 접속: **http://localhost:5174**

> 외유내강 버전은 `intro-web` 폴더에서 `python3 -m http.server 5173` → http://localhost:5173

## 구성

- 얼굴: 펜 선(SVG)으로 직접 그림 — 음악 버튼과 똑같은 2px 두께, 화면 크기와 상관없이 유지
- 홈 화면 아래 음악 버튼(▶/❚❚, 동그라미 없음, 다른 페이지에선 숨김) — `music/[They Long To Be] Close To You.mp3` 재생
- 홈: 얼굴은 가로 가운데, 세로는 가운데보다 살짝 위. 자막은 얼굴 바로 아래를 따라감. 들어오면 자막 "Hi, this is my personal page." → "Have fun looking around!" → 마지막에 인스타 @jang__jione_ (클릭하면 인스타로, 계속 남아 있음)
- 오른쪽 위 **핸드폰**(손그림, 처음엔 안 읽은 점 표시) 또는 **얼굴 클릭** → 펜으로 그린 핸드폰 채팅이 열림
  - jiwon: "Hi, my name is jiwon" → 답장 고르기
    - **How has your life been?** → "Let me show you!" → 바 화면(나)으로 이동
    - **What's your personality?** → "Round, mostly… come see!" → 성격 화면
    - **Show me your passion!** → "Okay… stand back!" → 열정 화면
- 열정 화면: 펜으로 그린 **모닥불**(돌 테두리 + 장작 + 일렁이는 불꽃 + 튀는 불티). 옆 **장작더미에서 장작을 끌어다 불에 넣으면** 불이 확 커지고 불티가 터짐. 안 넣으면 천천히 원래 크기로 줄고, 넣었던 장작도 하나씩 타서 사라짐
- 성격 화면: 왼쪽에 펜으로 그린 **동글동글한 무언가**(천천히 숨 쉬듯 출렁임) — 마우스를 대거나 누르면 가시가 **삐쭉** 튀어나왔다 들어가고 표정이 장난(윙크+메롱) 또는 짜증(찡그린 눈썹)으로 바뀜. 오른쪽에 설명 글 ("round & soft …")
    - **Bye** → "Bye! See you again :)" → 얼굴 화면으로
  - 핸드폰 다시 누르기 / Esc → 닫기. 핸드폰은 모든 화면에 있음 (바 화면에서 Bye로 홈 복귀)
- 바 화면: **왼쪽에 세로 바 + 사람**, 오른쪽은 나이에 맞는 사진 앨범
  - 바의 손잡이를 드래그(또는 ↑↓) → 아기 · 어린이 · 학생 · 지금 · 할아버지
  - 사람에 마우스를 올리면 활짝 웃으며 손을 흔듦 (단계마다 웃는 얼굴, 할아버지는 지팡이 반대 손으로)
  - 드래그하는 동안은 끊김 없이 변하고, 손을 떼면 가장 가까운 단계로 부드럽게 미끄러져 멈춤 (어중간한 모습으로 안 멈춤)
  - 얼굴은 홈 얼굴과 같은 그림체 (단계마다 따로 그림), 몸은 두께 있는 소매·바지·손·신발 (흰색으로 채워 겹침 처리)
  - 렌더링: 이미지 없이 숫자 몇 개로 선을 계산, 움직일 때만(프레임당 최대 1번) 다시 그림
- 바 화면: 바 · 사람 · 앨범이 한 덩어리로 **화면 가운데** 정렬
- 앨범: 바가 어떤 나이에 오면 그 나이 사진들이 **두 칸짜리 사진 띠**(세로 2칸 + 맨 아래에 그 나이 손글씨: baby · kid · student · now)에 담겨 나옴. **칸을 누르면 사진이 크게** 뜸 (바깥 클릭 / Esc로 닫기). 띠 높이 = 바 높이, 칸·테두리 모두 삐뚤빼뚤 떨리는 펜 선. 가족 액자 아래엔 "someday"
  - 사진 폴더 (최대 2장, 파일 이름 순서대로 위 칸부터): `photos/life/1_baby/` (바 0) · `2_kid/` (25) · `3_student/` (50) · `4_now/` (75). 1장이면 아래 칸은 빈 칸
  - 바 맨 위(100): "someday" 가족 **액자** — 이중 펜 테두리 안 가운데에 웃는 얼굴 넷 (뒷줄 아내 · 나(안경), 앞줄 딸 · 아들). 같은 펜 그림체, 선이 떨림
  - 사진이 없는 나이에선 "add photos to photos/life/○○/" 안내
  - 사람은 각 단계 근처에선 그 단계 모습 그대로 유지, 단계 사이에서만 변함
- (쉬는 중) 예전 '좋아하는 것' 코너들 — 지금은 바에서 빼둠, 코드는 남아 있어 다시 켤 수 있음:
  - **25 · 레코드 플레이어**: 펜으로 그린 턴테이블 + 가운데 구멍 뚫린 CD들. CD를 끌어 턴테이블에 올리면 착 붙어서 돌고, 톤암이 내려오고, 그 CD의 노래가 나옴. 다른 CD를 올리면 앞 CD는 제자리로, CD를 집어 들면 멈춤. 바를 다른 곳으로 옮기면 일시정지
    - CD: `music/cds/`에 **같은 이름**의 노래 + 표지 (예: `좋아하는노래.mp3` + `좋아하는노래.jpg`). 표지가 없으면 빈 CD로 나옴
  - **50 · 사진 더미**: 컬러 사진들이 오른쪽에 흩어져 놓임 (각 사진에 손그림 펜 테두리). 끌어서 옮기기 / 휙 던지면 미끄러지며 살짝 돌아감 / 잡은 사진이 맨 위로
    - 사진: `photos/pile/`에 넣은 이미지 전부 (이름 상관없음, jpg·png·webp·gif)
  - **100 · 지구본**: 펜으로 그린 탁상 지구본(받침대·반원 고리·23.5° 기운 축). 천천히 혼자 돌고, 마우스로 잡고 휙 돌리면 돌다가 다시 천천히. 삐뚤빼뚤한 대략적인 대륙 + 서울 점 + **USA · Switzerland · Iceland · Italy** 표시(점 + 손글씨 이름). 화면에 보일 때만 그림
  - 새 이야기 추가: `index.html`에 `<div class="moment" data-at="숫자">…</div>`를 하나 더 만들면 바에 점이 자동으로 생기고, 손을 뗄 때 그 지점에도 멈춤
- 손그림 애니메이션처럼 1초에 8번 프레임이 바뀌며 선이 떨림 (line boil)
